# Word 试卷英语题型提取与重新编号设计

## 目标

在现有选择题、填空题分类基础上增加英语阅读理解和英语完形填空。用户在上传前单选一个目标题型，批量上传多份 `.docx`，系统仅提取所选题型，按原文档及文档内出现顺序合并，并生成重新编号的 Word 或打印版 PDF。

系统只处理 Word Open XML 文档 `.docx`。旧版 `.doc`、PDF、图片和扫描件不属于本功能范围。

## 用户操作

1. 用户单选选择题、填空题、英语阅读理解或英语完形填空。
2. 用户选择一份或多份 `.docx`。
3. 系统读取全部文档，识别目标题型并显示预览。
4. 用户核对文章边界、小题归属、题型和答案对应关系。
5. 用户导出 Word，或通过打印样式保存 PDF。

改变单选项不会要求重新上传。已经解析的文档保留在当前页面内，系统根据新选项切换提取结果。

## 采用的实现方式

现有文档结构解析继续作为基础。系统读取 Word 段落、表格、自动编号、图片关系和 Office Math，不把整页转换成图片。

英语阅读和完形使用两层结构。

- 题组保存文章材料、题型、来源文档、原始顺序及所属小题。
- 小题保存原题号、正文块范围、新题号及答案解析引用。

这一结构使文章材料在导出中只出现一次，同时允许小题跨多份文档连续编号。页面范围裁切没有采用，因为它容易重复文章或包含相邻题。完全重建所有 Word 排版也没有采用，因为复杂公式和图片关系容易丢失。

## 识别规则

### 题型栏目

系统识别以下常见标题及其带题数、分值说明的变体。

- 选择题、单项选择题、多项选择题
- 填空题
- 阅读理解、阅读下面短文、阅读下列材料、Reading Comprehension
- 完形填空、完型填空、Cloze Test、完形阅读

显式栏目标题的优先级高于题干关键词。题干中偶然出现“阅读理解”或“完形填空”不会创建新栏目。

### 文章题组

英语栏目内出现“第一篇”“Passage 1”“Text A”“A 篇”等文章标记时，它们作为新题组边界。没有明确文章标记时，系统结合连续英文材料段、首个主问题题号以及下一篇材料起点确定边界。

每个题组由以下内容组成。

1. 文章标题和说明。
2. 正文材料、表格、图片和公式。
3. 按原顺序排列的小题及选项。

文章边界、材料和小题的关联没有足够证据时，整个候选范围进入待核对区。系统不把不确定的材料自动附到相邻文章。

### 完形填空

完形材料中的 `(1)`、`1`、下划线或其他空位标记属于文章正文。材料后的选择项按空位或题号关联为小题。系统不会把文章中的空位标记误判成独立文章。

### 普通选择题和填空题

继续使用现有主问题边界和题型规则。只输出用户当前选择的类别，其他已识别题目保留在内存中，便于用户切换类别。

## 重新编号

所选题型的输出小题统一从 `1` 开始连续编号。编号跨文章、跨源文档连续递增，新文章和新文档都不重置。

每个小题保存以下映射。

```text
来源文档 + 原题号 -> 输出新题号
```

选择题和填空题的主问题直接使用新题号。英语阅读和完形先输出一次文章材料，再输出该文章所属的小题。文章标题使用“阅读 1”“阅读 2”或“完形 1”“完形 2”，文章序号与小题序号分别计算。

原始自动编号在导出时移除，避免新旧编号同时出现。题目来源和原题号显示为辅助信息，不参与正式编号。

## 答案与解析

解析 Word 正文时不再丢弃独立的“参考答案”“答案与解析”“试题答案”章节，而是将其保存为答案块。

答案关联按以下优先级执行。

1. 同一文档内明确的文章标签和原小题号。
2. 同一题型栏目内的原小题号顺序。
3. 答案章节的连续顺序。

导出正文结束后增加“答案与解析”。英语题型按文章出现顺序分组，每篇文章下面列出所属小题的答案和解析，并使用重新编号后的题号。选择题和填空题按新题号顺序列出答案。

无法唯一关联的答案不会自动附加。页面会显示来源、原答案编号和候选题目，让用户选择对应小题。没有答案的文档仍可正常提取和导出。

## 数据结构

`QuestionType` 增加 `reading` 和 `cloze`。

`QuestionGroup` 保存以下字段。

```ts
interface QuestionGroup {
  id: string;
  sourceId: string;
  type: 'reading' | 'cloze';
  originalLabel?: string;
  materialStartBlock: number;
  materialEndBlock: number;
  questionIds: string[];
  issues: string[];
}
```

`ClassifiedQuestion` 增加可选的 `groupId`、`outputNumber` 和答案关联 ID。`ParsedExam` 增加答案章节块及其原始位置。批处理结果保存题组、答案项、按目标题型区分的编号映射和待核对项。

## 界面设计

上传区上方显示四个单选卡片。默认选择“选择题”。当前选择会显示在上传按钮和处理状态中。

结果页只展示当前所选类型，并显示以下统计。

- 提取到的文章数或普通题目数。
- 小题总数。
- 已匹配答案数。
- 待核对数量。

英语题型预览采用文章卡片。文章材料显示一次，小题作为卡片内的连续列表。用户可调整文章起止段落、把小题移入或移出题组、修改小题顺序以及修正答案关联。

导出按钮名称包含当前题型，例如“导出英语阅读理解 Word”。没有识别到目标题型时按钮保持禁用。

## 导出结构

英语阅读理解和完形填空的 Word 结构如下。

```text
标题

阅读 1 / 完形 1
文章材料
1. 小题……
2. 小题……

阅读 2 / 完形 2
文章材料
3. 小题……
4. 小题……

答案与解析
阅读 1 / 完形 1
1. 答案及解析
2. 答案及解析

阅读 2 / 完形 2
3. 答案及解析
4. 答案及解析
```

选择题和填空题保持单题列表结构，并同样使用连续新编号和末尾答案区。

## 错误处理

- 非 `.docx` 文件在选择阶段直接提示，不进入解析。
- 单个损坏文档不会中断其他文档。
- 没有目标题型时显示已读取的文件和“未发现所选题型”。
- 同段多题、文章边界不清、小题跨题组、原题号重复及答案关联冲突进入待核对区。
- 导出前显示题组数、小题数、答案匹配数和仍未解决的问题。

## 测试与验收

自动测试增加以下场景。

- 中英文题型标题及带题数说明的标题识别。
- 两篇阅读各自只保留一次材料，小题归属正确。
- 完形材料中的空位编号不会产生错误题组。
- 多份文档按上传顺序合并，小题连续编号且不重号。
- 切换单选项无需重新解析文档。
- 答案章节被保存，答案按文章顺序移到末尾并正确映射新题号。
- 原题号重复、缺失或答案冲突时进入待核对区。
- 导出的 Word 不包含旧自动编号，图片关系和公式节点仍有效。

使用真实样卷验收时至少包含两份阅读理解卷和两份完形填空卷，其中一份带答案解析，一份带图片、表格或 Word 公式。逐题核对文章范围、小题归属、新编号和答案映射。
