# 试卷归集台

这是一个纯前端的多份 Word 试卷整理工具。它在浏览器本地读取 `.docx`，识别题型栏目和主问题边界，并把题目归入选择题、填空题、解答题或待核对区。

## 使用

```powershell
npm install
npm run dev
```

浏览器打开终端显示的本地地址，选择多份 `.docx`。核对分类和题目边界后，可分别导出三类题目的 Word，或使用浏览器打印功能保存 PDF。

生产构建：

```powershell
npm run build
```

构建结果位于 `dist/`，可以部署到普通静态文件托管服务。

## 已实现

- 多份 `.docx` 批量读取，坏文件不会中断其余文件。
- 保留段落、表格、Word 自动编号、内嵌图片和 Office Math 公式节点。
- 识别选择题、填空题、解答题栏目，并用单题结构作为无标题文档的回退依据。
- 排除独立的参考答案章节，避免把小问和选项拆成主问题。
- 按来源文件和原题号追溯题目。
- 人工改题型、按段落边界拆题、合并相邻题、把漏识别片段加入题目。
- 分类 Word 导出时重新映射跨文档图片关系，避免同名图片互相覆盖。
- A4 打印样式，可通过浏览器“打印”保存 PDF。

## 第一版边界

- 输入格式为可编辑的 `.docx`。旧 `.doc` 需要先另存为 `.docx`。
- 整页扫描图片没有可编辑文字时会提示走扫描识别流程。
- 同一段落或同一个表格单元格中排了多道主问题时，页面会提示核对。复杂的段内拆分建议先在原 Word 中分段。
- 自动编号支持常见十进制主编号。多级自定义编号、文本框、SmartArt、特殊域和部分浮动对象需要人工核对。
- PDF 输出调用浏览器打印对话框。为获得最稳定的公式和复杂对象效果，也可以打开导出的 Word 后另存为 PDF。

## 验证

```powershell

```

自动测试覆盖 Word 结构读取、题目切分、题型分类、坏文件隔离、人工编辑状态，以及多文档图片和公式导出。
